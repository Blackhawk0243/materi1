Materi: Membuat Akun Scratch & Teori Logika "IF"

1. Cara Membuat Akun Scratch

Scratch adalah situs web untuk belajar membuat animasi dan game. Untuk menyimpan hasil karya, kita perlu membuat akun terlebih dahulu.

Langkah 1: Buka Situs Scratch

Ketik scratch.mit.edu di peramban (browser) Anda.

Setelah halaman terbuka, cari dan klik tombol "Join Scratch" (Bergabung) di sudut kanan atas.

Langkah 2: Buat Akun

  • Buat Nama Pengguna (Username). Hindari menggunakan nama asli Anda untuk keamanan.
  • Buat Kata Sandi (Password) yang mudah diingat oleh Anda, tetapi sulit ditebak orang lain.

2. Memahami Logika "IF" (JIKA)

Dalam pemrograman, kita sering menggunakan kata IF. Dalam bahasa Indonesia, IF berarti JIKA.

Kita menggunakan "IF" agar komputer bisa mengambil keputusan otomatis berdasarkan suatu kondisi tertentu.

Konsep Dasar

JIKA [Kondisi Terjadi] MAKA [Lakukan Sesuatu]

Contoh di Kehidupan Nyata:

JIKA (Kondisi yang terjadi) MAKA (Tindakan yang dilakukan)
Hujan turun dari langit Saya membuka payung
Lampu lalu lintas berwarna Merah Mobil dan motor harus berhenti
Menekan saklar lampu Lampu ruangan menyala

Blok "IF" di Scratch

Di Scratch, blok IF berwarna Oranye. Blok ini terlihat seperti huruf "C" atau mulut yang terbuka.

  • Bagian berbentuk segi enam (di atas) diisi dengan kondisi (contoh: menyentuh warna merah).
  • Bagian mulut blok (di tengah) diisi dengan perintah yang akan dilakukan (contoh: karakter bergerak).
if <touching color [#ff0000]?> then
  move (10) steps
end

3. Latihan Praktik: Mari Mencoba!

Sekarang buka aplikasi Scratch Anda. Cobalah 4 latihan di bawah ini untuk melihat bagaimana logika IF bekerja secara visual. Susun blok warnanya sesuai dengan petunjuk!

⌨️

Praktik 1: Menggerakkan Karakter

Buat agar karakter bisa bergerak ke kanan dan ke kiri setiap kali kita menekan tombol panah kanan atau kiri di keyboard.

Logika:
JIKA [Panah Kanan Ditekan] MAKA [Ubah X sebesar 10]
JIKA [Panah Kiri Ditekan] MAKA [Ubah X sebesar -10]

Bentuk Blok Asli:

when green flag clicked
forever
  if <key [right arrow v] pressed?> then
    change x by (10)
  end
  if <key [left arrow v] pressed?> then
    change x by (-10)
  end
end

🎯 Hasil Akhir (Stage Scratch):

Tekan ⬅️ ➡️
🍎

Praktik 2: Reaksi Menyentuh Benda

Tambahkan karakter Apel. Buat agar Kucing memunculkan teks balon "Nyamm!" saat menyentuh Apel.

Logika:
JIKA [Menyentuh Apel]
MAKA [Katakan "Nyamm!" selama 2 detik]

Bentuk Blok Asli:

when green flag clicked
forever
  if <touching [Apple v]?> then
    say [Nyamm!] for (2) seconds
  end
end

🎯 Hasil Akhir (Stage Scratch):

Nyamm!
🌋

Praktik 3: Menghindari Bahaya

Gambar kotak merah (sebagai lava). Jika karakter menginjak warna merah, ia akan otomatis pindah kembali ke titik awal (X:0, Y:0).

Logika:
JIKA [Menyentuh warna Merah]
MAKA [Pergi ke X: 0, Y: 0]

Bentuk Blok Asli:

when green flag clicked
forever
  if <touching color [#ff0000]?> then
    go to x: (0) y: (0)
  end
end

🎯 Hasil Akhir (Stage Scratch):

x:0, y:0
🎭

Praktik 4: Animasi Ganti Kostum

Setiap kali layar diklik menggunakan mouse, karakter akan berganti gaya (berganti kostum hewan lain).

Logika:
JIKA [Mouse diklik (mouse down)]
MAKA [Ganti ke kostum berikutnya]

Bentuk Blok Asli:

when green flag clicked
forever
  if <mouse down?> then
    next costume
  end
end

🎯 Hasil Akhir (Stage Scratch):

Klik Stage 🖱️
💡 Tips Penting: Agar komputer terus mengecek perintah IF (JIKA) kalian, jangan lupa memasukkan blok "IF" ke dalam pelukan blok "Forever" (Selamanya) yang juga berwarna oranye!
